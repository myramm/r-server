# 🖥️ XRDP LINUX DESKTOP - SOFTWARE & APPS CATALOG (40 KATEGORI)

> **Catatan Penting:**
> * **XRDP** adalah protokol Remote Desktop (bukan sistem operasi terpisah). Aplikasi di bawah ini diinstal pada sistem Linux (Debian 12 / Ubuntu 24.04 + XFCE GUI) dan dapat langsung digunakan secara visual melalui sesi Remote Desktop (XRDP Port 3389) atau melalui Web Dashboard 1-Click Installer.

## 🚀 Cara Instalasi:

1. **Via Web Dashboard (Paling Mudah - 1-Klik):**
   * Buka URL Web Dashboard VPS Anda: `https://<vps-domain>`
   * Masuk ke Tab: **`🛠️ Tool & Browser Installer`**
   * Cari software yang diinginkan lalu klik tombol **`🚀 Install`**.

2. **Via Remote Desktop GUI (XRDP):**
   * Sambungkan RDP Client ke `IP:PORT_XRDP` (User: `root`).
   * Buka **XFCE Terminal** di dalam desktop dan jalankan package manager distro (`apt`, `npm`, `pip`, `cargo`).
