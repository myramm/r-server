🔀 9Router — AI Gateway & Proxy
Proxy/Gateway cerdas antara coding tools (Claude Code, Cursor, Antigravity, Aider, Cline) dan multiple AI Providers.
• Dashboard: http://localhost:20128
• API Endpoint: http://localhost:20128/v1
• Install: npm install -g 9router
• Jalankan: 9router (atau background via pm2/nohup)
